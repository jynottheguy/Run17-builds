# Run17-builds

Selected STFC tools and builds.

## Run 17 — Trial 49

This build is based on the STFC Community Mod and includes additional features built on top of it.

### Features
- **F6 hostile attack shortcut:** selects the nearest visible hostile and initiates the normal attack action.
- **Occupied mining-node viewer:** select an occupied mining node and use ActionView to cycle between the occupying ship's cargo/loot and ship strength without running a normal scan.
- **Out-of-range viewing:** cargo/loot and ship strength can be viewed for players above or below your normal PvP hit range.
- **Attacking an occupied miner:** the viewer itself is informational. To attack the occupying ship, click the mining node again and use the normal attack action.
