# Run17-builds

Selected STFC tools and builds.

## Run 49

This build is based on the STFC Community Mod and includes the additional features we've developed on top of it.

### Features
- **F6 hostile attack shortcut:** selects the nearest visible hostile and initiates the normal attack action.
- **Occupied mining-node viewer:** select an occupied mining node and use ActionView to cycle through the occupying ship's cargo/loot and ship strength information.
- **Attacking an occupied miner:** after viewing the occupying ship, click the mining node again to use the normal attack action against it.
